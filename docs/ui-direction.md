# UI direction

Status: reconciled 2026-09-19 against current `apps/web/app/globals.css`, `apps/web/eslint.config.mjs`, and the [design system](design-system.md). The [design system](design-system.md) is normative for components, tokens, lint, and the Storybook workshop; this document keeps the product-presentation decisions that still hold and the locked direction they came from.

## Current truth

- Home is a shadcn app on the Base UI preset. Product code composes owned wrappers in `apps/web/components/ui` and never restyles their slots beyond layout classes.
- Theme: shadcn's stock neutral theme generated by the `base-nova` preset. Home overrides only `--primary`/`--ring` (Base blue `#0052ff`), `--primary-foreground` (white), and `--radius` (`0.25rem`). `--market-gain` and `--market-loss` remain for their chart consumers.
- Styling vocabulary is semantic tokens (`bg-card`, `bg-muted`, `text-muted-foreground`, `border`, `ring-foreground/10`, …). Hex/rgba, arbitrary-pixel, raw-palette, and detached class-string constants are lint errors. There is **no** `--home-*` alias layer, `--control-radius`, or `--panel-radius`; those names are history, not tokens.
- Type: the stock system sans and monospace stacks. Home bundles no font assets. Money and aligned numbers use `tabular-nums`; monospace is reserved for addresses, hashes, and code.
- Representative review viewport is 390 CSS pixels; 320px is a containment safety check, not the definition of mobile.
- Direction-1 craft intent that survives: one Base-blue primary action accent; Send, Receive, Sell, and Account stay quiet; percent change is green up / red down, never blue; no gradients, glass, heavy in-app shadows, or gamification chrome; flat panels on canvas separated by hairlines.
- Motion must earn its place through purpose (feedback, spatial continuity, state indication, preventing a jarring change), frequency, and content sensitivity. Frequently read financial surfaces stay still — functional balances, amounts, and positions never move for decoration. Tab ≤180ms, chip ≤120ms, CTA press 100–160ms; other motion stays comparably short. `prefers-reduced-motion: reduce` removes spatial and transform motion and keeps only short opacity/color transitions that aid comprehension; there is no decorative fallback and smooth scrolling stays `auto`.
- Do not put legal disclosures, eligibility essays, contract lists, source roster walls, "not an endorsement," or similar compliance copy on product screens (Home, Save, Invest, Borrow, Fund, etc.). Those belong only in **Account → Disclosures / Terms** (or an equivalent settings section), which Account should gain if missing.
- Review and confirm screens may show the **actionable** facts needed to complete an action (amount, fee, slippage, network). Do not turn those into catalog footnotes on list or discovery surfaces.

## Feature-module contract

Savings and Invest modules are still passed into `HomeExperience` through `savingsContent` and `investContent`. Those modules follow the same rules as the rest of the app: semantic theme tokens only, reusable presentation in owned `components/ui` variants or explicit component contracts, inline Tailwind utilities at the product use site, and flat surfaces separated by hairlines rather than gradients, glass, or shadows.

## History — Direction 1 "Vercel Editorial" (locked 2026-09-08)

Direction 1 locked the signed-in Home and Invest visual craft and kept Home shell v2 with Invest discovery v3. Base brand guidance reviewed September 7, 2026 still informed the palette: `https://www.base.org/brand`, `https://www.base.org/brand/color`, and `https://www.base.org/brand/typography`.

Its token block, kept verbatim for provenance:

```
--home-ink:        #0a0b0d
--home-muted:      #5b6270
--home-white:      #ffffff
--home-canvas:     #f7f8fa   /* page / shell behind panels */
--home-hairline:   #e6e8ec
--home-blue:       #0052ff
--control-radius:  8px
--panel-radius:    12px
```

- Canvas behind modules; white panels; 1px hairlines. Panel radius 12px, controls 8px.
- Near-ink `#0a0b0d` over pure black. Muted copy uses `#5b6270`.
- Base blue is the single primary action accent (Add money, Buy, active tab). Send, Receive, Sell, and Account stay outline / quiet.
- Percent change is green up / red down — never blue. Chart stroke is Base blue (~1.5–2px) with fill only if `rgba(0, 82, 255, 0.06)`.
- Region accent is a whisper on currency marks only.
- No gradients, glass, heavy in-app drop shadows, or gamification chrome.
- Motion is short and optical, and must earn its place: purpose (feedback, spatial continuity, state indication, preventing a jarring change), frequency, and content sensitivity decide. Tab ≤180ms, chip ≤120ms, CTA press 100–160ms; other motion stays comparably short. Frequently read financial surfaces stay still — functional balances, amounts, and positions do not move merely for decoration.
- `prefers-reduced-motion: reduce` removes spatial and transform motion, keeping short opacity or color transitions only when they aid comprehension. No decorative fallback, and smooth scrolling stays `auto`.
- Base Sans and Base Mono are not bundled because reuse rights for this project are unverified. Home uses a system sans-serif stack.

Superseded by the current truth above: the `--home-*` alias tokens and the 12px/8px radii were replaced when Home adopted the stock shadcn `base-nova` theme, which now carries the canvas/hairline/panel treatment through semantic tokens and a `0.25rem` `--radius`. The surviving decisions are restated under [Current truth](#current-truth) rather than deleted, and the locked direction remains part of the project's history. Earlier module-scoped CSS and the gray-scale alias layer are also gone; Savings and Invest content still enters `HomeExperience` through its props.
