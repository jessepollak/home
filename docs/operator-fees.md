# Operator fee records

A fee-bearing confirmed trade writes one normalized `operator_fee_records` row in the same transaction as confirmation. Its unique `action_id` references the action record; confirmation replay does not add another row. Zero-fee trades and other actions do not write fee records. A configured destination equal to the trading smart account is treated as no fee, because the transfer would be a self-transfer; the trade omits the fee leg and writes no record. The row preserves the fee's USDC base units, token identity, basis points, recipient, collection method, action kind, and recording time. It does not duplicate the action's transaction hash or outcome.

The operator revenue query joins fee records to actions. `collectedBaseUnits` counts only actions with a `succeeded` outcome, across all time. UTC daily totals count succeeded fees on the action's `outcome_recorded_at` date, falling back to the fee's `recorded_at`; the selected date range ends today and includes zero-filled days. A fee record whose action has no stored outcome yet reads as `unresolved` in the newest entries: Home does not distinguish a still-pending action from one whose result is unknown, so it does not claim either. Reverted and not-submitted actions are listed the same way, and succeeded actions appear too. Each entry reads its current result and transaction hash from the referenced action, rather than a copied fee-field value. Amounts remain exact decimal base-unit strings.

A `succeeded` outcome means Home attributed the submitted batch to the action's owner. Totals are therefore *expected* fees from succeeded actions, not a reconciliation against the chain: Home does not yet read the USDC `Transfer` log to the fee recipient, and an owner who dispatches the confirmed calls themselves without the fee leg, then reports that transaction, would count here. Treat the totals as an operator-facing estimate and the recent-fee transaction links as the on-chain record. Verifying each recorded fee against its transfer log is follow-up work.
