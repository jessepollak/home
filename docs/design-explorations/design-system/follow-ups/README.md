# Design-system follow-up coverage

The [library design system](../../design-system.md#follow-up-code-issues) explains the coverage rules and counts. Each numbered follow-up and its lettered subparts have their own file here; add a file for a new follow-up rather than appending to a shared table. The [operating manual](../../../operating-manual.md#design-handoff-coverage) defines the handoff contract.
