# Button

- `Button` in `apps/web/components/ui/button.tsx`.
- Review `Button` variants in the `ui-button` Storybook stories.
- `inline-status` pairs a 1.25rem optical height with a centered 2.75rem invisible pointer target for a short inline status label. Keep the expanded target clear of other controls; at desktop widths with a fine pointer, the expansion is omitted. Use the owned focus ring and popup-trigger semantics rather than resizing the control at the product call site.
