# Operator support inbox

- `operator-support-inbox--empty`, `operator-support-inbox--unavailable`: standalone production inbox states.
- `journeys-operator-support-inbox--empty-inbox`, `journeys-operator-support-inbox--unread-list`, `journeys-operator-support-inbox--open-conversation`, `journeys-operator-support-inbox--reply-sent`, `journeys-operator-support-inbox--resolve-reopen`, `journeys-operator-support-inbox--suggested-draft`, `journeys-operator-support-inbox--desktop-conversation`: injected, server-free operator journeys.
- `journeys-operator-support-inbox--needs-reply-list`, `journeys-operator-support-inbox--needs-reply-list-desktop`: list rows show `Needs reply` for operator-handled conversations waiting on a reply and `Assistant` for assistant-handled ones.
- `journeys-operator-support-inbox--assistant-handled`, `journeys-operator-support-inbox--assistant-handled-desktop`, `journeys-operator-support-inbox--take-over`, `journeys-operator-support-inbox--take-over-desktop`, `journeys-operator-support-inbox--reply-takes-over`, `journeys-operator-support-inbox--hand-back-unavailable`: handler control (`Take over` / `Hand back to assistant`), reply as implicit take-over, and the inline message when the assistant can't take the conversation back.
- `journeys-operator-support-inbox--settings-unavailable`, `journeys-operator-support-inbox--settings-unavailable-desktop`, `journeys-operator-support-inbox--settings-configured`, `journeys-operator-support-inbox--settings-configured-desktop`: the Support assistant panel on `/admin/support` with the `Assistant unavailable` note and with a configured write-only key.
- `ui-support-message--customer`, `ui-support-message--operator`, `ui-support-message--assistant`; `ui-rail-nav--unread`: owned component states.
