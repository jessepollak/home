# Architecture audit — September 12, 2026

Audit of `main` at `b9ecca1` against `home-is-thin.md` (five invariants, deliberate data model, client architecture) and the Rainbow teardown lessons. Two independent read-only auditors (server + funding seam; client) produced the findings; the coordinator verified the load-bearing claims (F1, F4, A-12, A-21) by hand and wrote the plan. Companion: [Design-system audit](design-system-audit-2026-09-12.md).

## Summary

- **No invariant is violated.** Server-authored calldata, verified scope, `bigint` amounts, `idempotencyKey`/EIP-5792 id = action id, and the owner fence all hold on both sides. The one high-severity finding (A-01) is a hard-coded token address table inside the funding receipt verifier that shadows the shared catalog.
- **The reset left ~2,500 LOC of unreachable server code**: `server/trading/{cdp,balance,prepare}.ts`, the proof half of `money-actions/receipt.ts` plus `/api/transfer-receipt`, `portfolio/valuation-rpc.ts`, and the legacy Ripio island (second order store, second state machine, four tables never migrated). Plus ~1,000 LOC of tests that only test it.
- **Deliberate state drifted**: `home_auth_nonces` is created at runtime and is not in the deliberate list; `user_settings` has no reader or writer; funding runs its own SQL executor and pool; `/api/activity` probes Postgres on every page for `recordedOperations`, which no UI reads; two parallel prepare routes (`POST /api/savings/actions`, `POST /api/borrow`) still insert `actions` rows beside `/api/actions/prepare`.
- **Two Rainbow lessons are half-applied.** The per-owner persisted query cache never hydrates (cleared in a layout effect before the effect that restores it), so a reload never paints from cache. Only Balances stays mounted; Home, Activity, Save, Invest remount on every tab change, and only Send is `?flow=`-addressable.
- **Invalidation and formatting are fragmented**: three invalidation sites with two different scope lists and a prop-drilled `onTransferConfirmed`; Activity's query key embeds a mount-time timestamp so invalidation refetches a stale window and the Home teaser never shares cache with the Activity page; five feature-local base-unit formatters and five `Intl`/`toLocale*` calls bypass `shared/formatting` (the Send toast and the balance row format the same amount differently).
- **Observability is inverted**: reads (portfolio, activity) emit structured events; the paths that move money (`server/actions/*`, `server/funding/core/*`) emit nothing and swallow causes into generic 5xx codes.
