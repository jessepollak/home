- **Paused corridor (operator setting)**: a corridor paused in Admin → Settings → Money in and out is absent from the method list for a customer with no order there, and quotes, order creation, verification starts, and new cash-outs are refused with `<Provider> is no longer offered here.` (order-flow.tsx). A customer who already has an open or ambiguous order in that corridor still sees the row (`resumeOnly` as an additive field on the onramp binding, contracts/providers.ts v3, so an older client ignores it); selecting it opens that exact order's prompt with `Continue deposit` and, for awaiting-payment orders, `Cancel deposit`, but no `Start new deposit`, and never requests a quote. The resume read is scoped to the binding's provider and payment method (`GET /api/funding/orders?region=&providerId=&paymentMethod=`), so a newer order in the same region does not hide it; every resume response must carry the versioned open-order envelope (`{version: 1, order}`, contracts/open-order.ts), so an older or unrecognised response is retryable rather than an empty result. When no matching order is found the row disappears and every healthy row stays usable; an unreadable, out-of-scope, or failed resume read shows `Home couldn't check your open deposit. Retry.` without disabling other corridors or clearing the selection. Closing and reopening the sheet clears the selection, so a late resume result never opens a prompt on a later visit.
- **Home-side checkout cancellation**: awaiting-payment prompts show `Continue deposit` plus `Cancel deposit`; economics review keeps `View payment instructions` plus Cancel, and payment-instruction status screens keep Cancel in the footer. X only closes. The pressed Cancel loads and disables duplicate requests; errors preserve Continue and Cancel, and a payment race refetches to `Payment received`. Successful prompt cancellation goes directly to a fresh deposit path (paused corridors return to methods); status cancellation shows `Deposit cancelled` or `Checkout timed out`, warns that paid funds can still arrive, and offers `Start new deposit`. Unknown provider status says `Checking deposit status` and `Don't pay again`; a trusted iframe load error offers cancel-and-restart recovery. Home never claims provider cancellation or a refund. Closed checkouts stop client polling but can still reconcile on the server.
