### `account-settings`
- **Entry context**: account · `/?account=settings` (dashboards commit `?account=settings`, shell.tsx `openAccountSettings`) · signed-in verified · signed-in seed · header profile mark (`ProfileMark`, shell-chrome.tsx) → settings; or goto `/home?account=settings`.

- **Live**: read-only
- **Owned paths**: `apps/web/client/account/account-settings.tsx`, `apps/web/client/account/account-route-provider.tsx`, `apps/web/client/account/cdp-client.tsx`, `apps/web/client/account/use-invite-link.ts`, `apps/web/shared/invites/**`, `apps/web/client/home/shell.tsx`, `apps/web/client/home/use-show-small-balances.ts`, `apps/web/client/appearance/**`, `apps/web/shared/appearance/**`
- **Reach**:
  1. `goto "/home?account=settings"`
  2. `expect "Account"`
- **Notes**: The fixture-session helper seeds signed-in state and fixtures. The Chromium smoke opens the header profile mark with the keyboard, asserts focus enters the settings region, closes through Done and browser Back, restores the exact opener, exercises deep-link and forward-history entry, and verifies every primary-navigation `aria-controls` target remains unique and present. Live: Peer availability varies by deployment and corridor (`PEER_OFFRAMP_ENABLED`, `apps/web/server/funding/providers/peer/manifest.ts`). Production exposed the Cash App path and a live review on 2026-09-24; snapshot current provider availability rather than assuming it is off.
- **Opener contract**: Header and rail account controls already pass their activating DOM button explicitly to the shell. A deep-link/history entry has no activation opener; closing intentionally falls back to a visible rail/header control, then the panel when neither exists. [Routing Playwright](../../../../apps/web/tests/browser/routing.pw.ts) covers exact-opener return, deep-link and Forward entry; [primary-navigation component tests](../../../../apps/web/components/primary-navigation.test.tsx) cover rail currentTarget threading.
- **Expect**: region `aria-label="Account settings"` receives programmatic focus without selecting an input; `Show small balances` switch (`getByRole("switch", { name: "Show small balances" })`, mobile-geometry.pw.ts; owned by client/home/use-show-small-balances.ts + account-settings region of shell.tsx). `Appearance` radiogroup (`getByRole("radiogroup", { name: "Appearance" })`) has Light, Dark, and System radios, with one checked; selection updates immediately via shell.tsx. Sign-out control and region selector live here (shell.tsx passes `regionId`, `resolutionSource`, `onRegionChange`, `onSignOut` to client/account/account-settings.tsx). `Invite friends` appears between Account and Disclosures & terms for an available signed-in invite link; the full link is selectable and Copy copies its absolute URL. Share appears only when the Web Share API is supported. `Support` row opens the Support sheet, with `Message us` and an unread count badge when replies arrive; the header profile mark has an unread dot and accessible count.
- **States**: preference not ready (`isPreferenceReady`); region override messages (`preferenceMessage`); appearance Light / Dark / System (including system changes) and storage-unavailable announcement in the polite preference status; narrow 320px row wraps the radiogroup under its title; invite-link loading shows a labelled skeleton, unavailable or missing account hides the section, and other errors show Try again; support sheet loading, empty, and load-error retry.
- **Regions**: the Country selector lists only the operator's offered countries (all configured countries in fixture sessions, which have no database). A saved country that is no longer offered shows an empty selector with Home in the global presentation.
- **Evidence**: screenshot; DOM snapshot; console/errors.
- **Owned by**: `apps/web/client/account/account-settings.tsx`, `apps/web/client/home/shell.tsx`, provider boundary `apps/web/client/account/account-route-provider.tsx`.
- **Unknowns**: none; the country selector is described by `Country` / `Sets how money is shown`, and the button is labelled `Sign out`.
