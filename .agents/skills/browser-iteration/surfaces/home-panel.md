- **Pull-to-refresh**: Only the verified Home scroll owner captures a downward drag from the top; the header and navigation stay pinned while the content moves. The React pathname update matching the popped entry retains the restore; leaving that pathname cancels pending retries and expiry immediately so the neighbouring page can persist its own scroll. Replacement restores, owner changes, user scroll intent, and unmount cancel obsolete work (`shell-scroll-history.pw.ts` and `use-shell-document-scroll-restoration.test.ts`).
