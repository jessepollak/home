# CDP Swaps on Base (#616, #980)

Any exact Base ERC-20 other than USDC or a tokenized stock can request a USDC-paired trade. A quote determines availability per amount and route; there is no catalog gate or liquidity floor. `resolveTradeAsset` validates asset identity, `buy-policy.ts` holds the buy-only operator-removal seam, and `erc20-execution-identity.ts` reads code, decimals and optional wallet balance from chain. Configured decimals must match chain decimals. Display prices and indexed balances never supply execution amounts.

`GET /api/trades?assetId=<id>` privately reports provider, account, signer and token readability, the current chain balance and buy policy. `prepare.ts` verifies signer and token identity at latest, converts sell-all using the chain balance, requests an executable quote and checks the pinned Base block, registry Settler, Permit2 nonce, RFQ maker permits, balance and allowance. A full sell whose pinned balance falls below the latest read fails; it never issues a partial review. Exact token approval to canonical Permit2 precedes the swap only when chain allowance is short. A network-fee approval, when selected, precedes both.

`stock-eligibility.ts` guards stock buys against the trusted edge request country at prepare and confirm, including signed replays; sells to Base USDC remain reduce-only from any country. The private, session-authorized `GET /api/trades/stock-eligibility` reports buy eligibility and sell eligibility. Missing or invalid country returns `TRADE_STOCK_RESTRICTED` (403) for buys. The current any-token trade path excludes stocks. The single `provider-refusal.ts` classifier maps the exact token-authorization refusal to `TRADE_NOT_ROUTED`, minimum-amount refusals to `TRADE_BELOW_MINIMUM`, and other 400/404/422 CDP error bodies to `TRADE_ROUTE_UNAVAILABLE` without returning provider text; outages return `TRADE_UNAVAILABLE`.

`quote.ts` binds the exact pair, Permit2 spender and amount, recipient, receive minimum and registry Settler. Supported Settler actions, pool restrictions, RFQ maker capacity and slippage checks fail closed; unknown selectors report an unavailable route. Its deterministic Settler input-spend model tracks fee and swap consumption in action order, assuming each AMM leg consumes its allotted input; unprovable, underfilled or overfilled input yields a stale quote so retry requests a fresh route, and multi-leg router-funded routes model only V3 and RFQ legs. Home removes the inner UNISWAPV2, MAVERICKV2 and UNISWAPV3 minimum-output words in the reviewed call; Settler's outer slippage record binds the reviewed minimum. `finalize.ts` verifies the reviewed owner signature and appends it to the exact pre-signature call. Quote expiration is bounded by the earliest permit deadline minus 30 seconds and two minutes from validation; confirm replay and retry refuse expired trades.

Provider refusals and an illiquid quote with a liquid reference-size price distinguish below-minimum from route-unavailable; failures of that secondary price check remain route-unavailable. The checkpoint (`bun run --cwd apps/web cdp-swaps:checkpoint --taker 0x… [--token 0x…] [--buy-usdc 1] [--sell 0.00001]`, or `--sweep --tokens 0xa,0xb,… --buy-usdc 0.10`) requests sanitized, non-funded quotes without signing or broadcasting. Chain failure still reports provider liquidity and action selectors, with unverified actions and exit 2. Funded buy/sell proof remains outstanding.
